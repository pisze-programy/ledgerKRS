Connect an agent

Your stack. Our data.

MCP works with any agent that speaks JSON-RPC. If you prefer function calling, the tool definition is a few lines.

Agents

Claude (Anthropic) ChatGPT / OpenAI Gemini Microsoft Copilot DeepSeek / Qwen / Kimi Llama / Mistral / Bielik opencode Perplexity

How to connect

  1. 1. POST /api/account — you get an api_key and 100 credits.
  2. 2. Add the MCP server /mcp with the x-api-key header.
  3. 3. The agent calls tools — data comes back as JSON.
{
  "name": "sprawdz_firme",
  "description": "Dane firmy z KRS po NIP",
  "parameters": {
    "type": "object",
    "properties": { "nip": { "type": "string" } },
    "required": ["nip"]
  }
}

The agent runs a plain GET /api/dane?nip=… with the key. Or you add /mcp — and write no code.
