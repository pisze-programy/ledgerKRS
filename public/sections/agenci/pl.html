Podłącz agenta

Twój stack. Nasze dane.

MCP działa z każdym agentem, który rozumie JSON-RPC. A jeśli wolisz function calling — definicja narzędzia to kilka linii.

Agenty

Claude (Anthropic) ChatGPT / OpenAI Gemini Microsoft Copilot DeepSeek / Qwen / Kimi Llama / Mistral / Bielik opencode Perplexity

Jak podłączyć

  1. 1. POST /api/account — dostajesz api_key i 100 kredytów.
  2. 2. Dodaj serwer MCP /mcp z nagłówkiem x-api-key.
  3. 3. Agent woła narzędzia — dane wracają jako JSON.
{
  "name": "sprawdz_firme",
  "description": "Dane firmy z KRS po NIP",
  "parameters": {
    "type": "object",
    "properties": { "nip": { "type": "string" } },
    "required": ["nip"]
  }
}

Agent wykonuje zwykły GET /api/dane?nip=… z kluczem. Albo podłączasz /mcp — i nie piszesz kodu.
