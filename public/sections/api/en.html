REST API

Business data as an endpoint.

GET + JSON. No SDK, no OAuth. One endpoint, one credit.

EndpointWhat it returns
/api/daneCompany report by KRS or NIP
/api/sprawozdaniaStatements, position by position
/api/katalogFilters, counter, metrics
/api/szukajSearch by name, NIP, KRS, REGON
/api/branzePKD branches
/api/pkd/{code}Branch report
/api/balanceCredit balance
/api/zuzycieUsage per endpoint
