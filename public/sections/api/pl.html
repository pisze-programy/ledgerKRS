REST API

Dane gospodarcze jako endpoint.

GET + JSON. Bez SDK, bez OAuth. Jeden endpoint, jeden kredyt.

curl "{{BASE}}/api/dane?krs=0000222483" \
  -H "x-api-key: $KEY"

EndpointCo zwraca
/api/daneRaport firmy po KRS albo NIP
/api/sprawozdaniaSprawozdania, pozycja po pozycji
/api/katalogFiltry, licznik, metryki
/api/szukajSzukanie po nazwie, NIP, KRS, REGON
/api/branzeBranże PKD
/api/pkd/{kod}Raport branżowy
/api/balanceStan kredytów
/api/zuzycieZużycie per endpoint
