# Polish company data from KRS

**No UI. Through API and MCP.**

Public data about Polish companies: registry data, financial statements, indicators, valuation, risk, connections, MSiG and KRZ. We serve the data. You or your agent build the view.

## Business data as an endpoint

GET + JSON. No SDK. No OAuth. One call = one credit.

| Endpoint | What it returns |
|---|---|
| `/api/dane?krs=` | Company report |
| `/api/sprawozdania?krs=` | Statements, position by position |
| `/api/katalog?...` | Filters, counter, metrics |
| `/api/szukaj?q=` | Search by name, NIP, KRS, REGON |
| `/api/branze` | PKD branches |
| `/api/pkd/{code}` | Branch report |
| `/api/balance` | Credit balance |

```bash
curl "{{BASE}}/api/dane?krs=0000222483" -H "x-api-key: $KEY"
```

## MCP for agents

Your agent pulls data through MCP tools. Nine tools: company report, statements, search, filters, branches, PKD report, balance, credits, usage. The agent decides when to ask. Tool descriptions live in `SKILL.md`.

## Catalog and branches

Filters: revenue, profit, PKD, voivodeship, ratios, growth. Counter and four metrics per company. Branch reports: summary, size, biggest firms, geography, percentiles.

## Start in three steps

1. Create an account:

```bash
curl -X POST -H "Content-Type: application/json" \
  -d '{"email":"you@example.com"}' "{{BASE}}/api/account"
```

2. Use the `api_key` from the response.

3. Ask about a company:

```bash
curl "{{BASE}}/api/dane?nip=7791011327" -H "x-api-key: $KEY"
```

## Where the data comes from

The data comes from public registers: the National Court Register (KRS), the Court and Economic Monitor (MSiG) and the National Debtors Register (KRZ). The KRS OpenAPI is free. You pay only for our layer: parsing, indicators, valuation and easy access.
