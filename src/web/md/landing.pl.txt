# Dane polskich firm z KRS

**Bez UI. Przez API i MCP.**

Publiczne dane o polskich spółkach: rejestrowe, sprawozdania finansowe, wskaźniki, wycena, ryzyko, powiązania, MSiG i KRZ. Serwujemy dane. Ty albo Twój agent składa widok.

<span class="badge">100 kredytów gratis</span> <span class="badge">1000 kredytów za 9,99 USD</span> <span class="badge">1 kredyt za zapytanie z danymi</span>

## Dane gospodarcze jako endpoint

GET + JSON. Bez SDK. Bez OAuth. Jedno zapytanie = jeden kredyt.

| Endpoint | Co zwraca |
|---|---|
| `/api/dane?krs=` | Raport firmy |
| `/api/sprawozdania?krs=` | Sprawozdania, pozycja po pozycji |
| `/api/katalog?...` | Filtry, licznik, metryki |
| `/api/szukaj?q=` | Szukanie po nazwie, NIP, KRS, REGON |
| `/api/branze` | Branże PKD |
| `/api/pkd/{kod}` | Raport branżowy |
| `/api/balance` | Stan kredytów |

```bash
curl "{{BASE}}/api/dane?krs=0000222483" -H "x-api-key: $KEY"
```

## MCP dla agentów

Twój agent pobiera dane przez narzędzia MCP. Dziewięć narzędzi: raport firmy, sprawozdania, szukanie, filtry, branże, raport PKD, stan, kredyty, zużycie. Agent sam decyduje, kiedy zapytać. Opis narzędzi znajdziesz w pliku `SKILL.md`.

## Katalog i branże

Filtry: przychody, zysk, PKD, województwo, wskaźniki, wzrost. Licznik i cztery metryki per firma. Raporty branżowe: podsumowanie, rozmiar, największe firmy, geografia, percentyle.

## Start w trzech krokach

1. Załóż konto:

```bash
curl -X POST -H "Content-Type: application/json" \
  -d '{"email":"ty@przyklad.pl"}' "{{BASE}}/api/account"
```

2. Użyj `api_key` z odpowiedzi.

3. Zapytaj o firmę:

```bash
curl "{{BASE}}/api/dane?nip=7791011327" -H "x-api-key: $KEY"
```

## Skąd pochodzą dane

Dane pochodzą z publicznych rejestrów: Krajowego Rejestru Sądowego, Monitora Sądowego i Gospodarczego oraz Krajowego Rejestru Zadłużonych. KRS OpenAPI jest darmowy. Płacisz tylko za naszą warstwę: parsowanie, wskaźniki, wycenę i wygodny dostęp.
